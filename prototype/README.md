# 速记（/note）

双栏速记已接到落笺后端。打开服务后访问 <http://127.0.0.1:8765/note>。

左边 Ctrl+Enter 按 `{source, text, important, media}` 写入 `desk.db`，右边从 `GET /api/notes/日期` 读取，点进去改会 `PUT` 回同一组条目。不再使用 localStorage 当正文仓库。

版式与交互仍是这一页：作者在上、写字在下；Ctrl+Enter 记下；点右边整组改。图片落到 `data/media/YYYY-MM-DD/`。

## 版式

```
笺 速记                                      示例  清空   2026/9/21
──────────────────────────────────┬────────────────────────────────
                                  │  查…                    复制
 ○  Agent  策略  VITO  老王  ＋    │  2026年9月21日
                                  │
 （一大片写字的地方）               │  VITO
                                  │  中午中债和地产一起涨，预测降准降息
                                  │  新规要求封顶才能卖，账期变长
                                  │
                                  │  雨神
                                  │  明天祖训完了看承接
```

右边就是你 `data/seed.txt` 里那套：**日期一行 → 作者一行 → 内容垒起来**。

- **作者在上，写字在下**。点名字＝换人；`○` 是未署名（空位，不写字）；`新作者` 悬浮输入新作者。
- **作者名忽略大小写**：`vito` / `Vito` / `VITO` 是同一个人，沿用先写下的那种写法，不会分裂成三个 chip。历史数据里已经存在的变体在载入时自动合并。
- **新名字直接记**，不校验、不提示、不用先登记。
- **回车换行，Ctrl+Enter 记下**，整段粘贴也行。框选一段再 Alt+Enter，把材料放进检索窗，自己写下问题再去问。窗可以折起或关掉；右上角「对话」是已经问过的记录。
- **界面上没有任何图标**，所有操作要么是文字，要么是键盘。

## 改内容：鼠标悬浮到某个作者的内容上，点一下就整段改

不用先找按钮。鼠标移到某个作者的内容上，那一组会轻轻浮起来、右边出现「点一下改」，点一下，**这个作者今天说的所有内容**就变成可编辑区，同时整组抬起一级、左侧出现一道绿色竖条。

**改的时候排版不会跳。** 编辑态里每一条仍是一个独立的块，`padding` 和 `line-height` 与静止态逐像素对齐（测试实测每条 y 偏移 0.0px、高度 0px 差、整组高度 0px 差）。悬浮效果只用 `background` / `box-shadow`，这两样不占布局，所以鼠标划过也不会把内容推开。

- 想改哪句改哪句，想删哪条删哪条，直接编辑。
- `Enter` 新起一条，`Shift+Enter` 在同一条里换行（和左边输入框一个手感）。
- `Ctrl+B` 加粗＝标为重要；`Ctrl+Enter` 存；`Esc` 撤。
- 右栏顶部会显示「N 条重要」，一眼看到今天标了几条。
- **要把一条内容从 A 挪到 B**：在 A 里选中它 `Ctrl+X` → 点进 B → 光标停在末尾直接 `Ctrl+V`。末尾粘贴会自动新增一条，不会黏在上一行屁股后面。
- **图片在编辑区里就是一条 `[图]`**：删掉这条就等于删掉图片，挪动这条就等于挪动图片；真图在编辑区下方照样显示，点一下不会消失。
- 点空白处、点搜索框、按 `Ctrl+Enter` 都会保存。

## 送进后端时，"重要"是一个字段，不用去正文里找

加粗在文本里就是 `**…**`，纯文本复制出去后端也能认。但这不该靠解析——记录层直接给出结构化载荷：

```json
{
  "date": "2026-09-21",
  "items": [
    { "source": "策略", "text": "**混天绫加仓亨通，白银有色**", "important": true,  "media": null },
    { "source": "策略", "text": "稳健博弈小幅拿中际旭创",          "important": false, "media": null },
    { "source": "Agent", "text": "",                              "important": false, "media": "fmua…" }
  ]
}
```

- `source` 是字段，不是靠猜。
- `important` 是布尔字段，后端不用正则去数星号。
- `media` 是 `YYYY-MM-DD/文件名`，文件在 `data/media/` 下。

控制台里 `window.luojianStructured()` 可以取到当前后端返回的载荷。

## 文字格式：只有一个动作，Ctrl+B

**加粗就是"重要信息"**，没有别的格式，没有浮动工具栏，没有颜色。

- 在右边点作者的内容进编辑态，选中文字，`Ctrl+B`（Mac 用 `⌘B`）→ 加粗。
- 加粗过的行，行首会出现一道很轻的竖边，方便一眼扫出今天哪些是重点。
- 再按一次 `Ctrl+B` 取消加粗，也就不再是重要。
- 存进去的是 `**文字**`（Markdown 加粗）。选 Markdown 是因为**落笺本身就把正文当纯文本存、按 Markdown 导出**；富文本编辑器存 HTML / Delta 会直接打断现有管线，行内标记存进去还是纯文本，复制、导出、回灌都不用转换。
- 编辑态下右栏顶部会显示一行提示：`Ctrl+Z 撤销 · Ctrl+Shift+Z 重做 · Ctrl+B 加粗＝标为重要 · Ctrl+Enter 存 · Esc 撤`。
- 存进后端之后，不在编辑态时再按 `Ctrl+Z`，会把刚才那组的删除或修改撤回去；`Ctrl+Shift+Z` 重做。

之前那套「重点 / 多 / 空」按钮和颜色已经全部删掉。

## 增删改查

| | 怎么做 |
|---|---|
| 增 | 左边写，Ctrl+Enter |
| 查 | 右栏左上角搜索框，过滤 + 命中处高亮 |
| 改 / 删 | 点作者的内容 → 整组变可编辑 → 直接改 |
| 改归属 | 在源作者里 `Ctrl+X`，点进目标作者，`Ctrl+V` |
| 标重要 | 编辑态里选中 → `Ctrl+B`（加粗即重要） |

## 图片

**直接 Ctrl+V 粘截图**，或者把图片文件拖进左栏。图片挂在当前选中的作者名下，右边显示缩略图，点开看大图。

- 存 `data/media/YYYY-MM-DD/`，单张上限 8MB。
- 复制出来的文本里，图片那行是 `[图]` 占位。

## 作者不再靠猜

右边仍是裸作者名。速记写入走结构化字段，`老王` 就是 `老王`，不会被并到上一行作者。日笺页的「粘贴大段原文」仍走 `parse_notes`，那条路径才会猜来源。

cd D:\codex测试\desk-notes
python prototype\_smoke.py         # 交互断言 + 两窗口读同一后端 + 剪贴板
python prototype\_layout_shift.py  # 点进编辑态逐条量 y / 高度；重要字段出处

三份 Playwright 脚本会拉起隔离数据库的临时服务，不写真实 `data/desk.db`。

## 已知边界

- 日笺「粘贴整理」仍可能把单独一行的新作者名当成正文。速记 Ctrl+Enter 这条路没有这个问题。
- 清空某一天会删掉当天卡片和对应图片。
